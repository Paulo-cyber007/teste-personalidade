Finalidade: este projeto demonstra a criação de formulários, interfaces web e mecanismos de consentimento para fins educativos.

Dados pessoais: o formulário solicita nome, email e data de nascimento para ilustrar campos de recolha. Nesta versão, os dados não são enviados para um servidor nem guardados numa base de dados. O cálculo do resultado ocorre localmente no navegador.

Consentimento simulado: ao marcar a caixa, confirmas que leste as condições e aceitas a simulação de tratamento local dos dados introduzidos nesta demonstração. Não existe partilha efetiva de dados pelo código.

Privacidade: num serviço real, o responsável pelo tratamento teria de informar sobre as finalidades, a base legal, os prazos de conservação, os destinatários e os direitos dos titulares.

Limitações: o resultado é lúdico, não é um diagnóstico nem uma avaliação psicológica validada.
