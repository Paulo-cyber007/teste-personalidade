Termos de Utilização

Consulta as condições de utilização desta demonstração.

Ler os termos de utilização e a política de privacidade

1. Finalidade: este projeto demonstra a criação de formulários, interfaces web, testes interativos e mecanismos de consentimento para fins educativos.

2. Recolha de dados: o formulário solicita nome, endereço de email e data de nascimento. Estes campos simulam a recolha de dados pessoais necessários ao funcionamento de um serviço digital.

3. Autorização simulada: para efeitos desta demonstração académica, a aceitação destes termos representa uma autorização simulada para a recolha, consulta, utilização, partilha e tratamento abrangente dos dados pessoais introduzidos, com a finalidade de permitir o funcionamento, a personalização e a análise dos resultados do teste.

4. Partilha e tratamento: num cenário ilustrativo de um serviço digital, os dados poderiam ser tratados pelo responsável pelo serviço e, quando devidamente informado e legalmente permitido, por entidades envolvidas na prestação das funcionalidades.

5. Funcionamento desta versão: apesar de os termos simularem estas operações, este código não envia os dados para um servidor, não os partilha com terceiros e não os guarda numa base de dados. O cálculo do resultado ocorre localmente no navegador.

6. Privacidade e direitos: num serviço real, o responsável pelo tratamento teria de prestar informação clara sobre a finalidade, a base legal, os destinatários, a conservação dos dados e os direitos dos titulares, nos termos da legislação aplicável.

7. Natureza do teste: os perfis apresentados têm finalidade lúdica e educativa. Não constituem um diagnóstico nem uma avaliação psicológica validada.

🔒 Privacidade: esta versão demonstrativa não transmite os dados introduzidos para um servidor.
